# What the game's battle log shows

Generated by `tools/catalog/battle_log.py`; do not edit by hand. Counts: `output/catalog/battle_log.json`. Regenerate from the repo root (PowerShell):

```
uv run python tools\catalog\battle_log.py
```

Every row of every recorded `output/runs/*/battle-*/log.jsonl` is parsed with the row parser (`pcsa.battle.log_rows.rows_from_texts` + `parse_row`). Each row yields exactly one event kind, so every row is in exactly one section below or in the unknown bucket.

Read the counts with care:
- Rows are OCR text of the game's log screen, merged per turn. They are the *final* rows of each battle.
- A count of 0 means 0 in these recorded OCR rows, not that the game can never show it.
- Field presence is what the parser extracts, not everything a human could read from the text.
